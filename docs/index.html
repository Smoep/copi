Why Copi?

Your Mac remembers one copy. Copi remembers the useful ones.

Copy normally while browsing or writing. Copi quietly builds a history you can search when the latest clipboard is no longer the item you need.

Using Copi

From clipboard history to the right paste.

Copi watches for genuine changes to the macOS clipboard. When you copy text, an image or another supported item, it adds an encrypted entry to History. Opening Copi does not replace the clipboard until you actually choose something.

“Open Copi” in this guide means use the global shortcut you chose in Settings. A fresh installation uses ⌘J, but that combination is only the default and can be replaced.

Paste an earlier item

  1. Place the cursor in the application where the item should go.
  2. Open Copi with your configured shortcut.
  3. Point to a result to highlight it and check that it is the item you want.
  4. Click the row to paste it. As a keyboard alternative, move with ↑/↓ and press Return.
  5. Copi verifies the destination, places the selected data on the pasteboard and dispatches ⌘V.

If Automatic Paste Events permission is unavailable, Copi explains that nothing was copied or pasted instead of silently changing the pasteboard.

Optional: paste by visible number

  1. Open Copi with your configured shortcut.
  2. Find the small number beside the result you want.
  3. Press ⌘1 through ⌘7 to choose and paste that row directly.
  4. Scroll to bring another group of seven rows into view when needed.

This is an accelerator, not a required workflow. You can always point and click the full row instead.

Search the whole collection—or just one part

Start typing after opening Copi. In All Clipboard, Search looks through clipboard history and every Favorite’s optional name and content. Search becomes scoped when you choose a Favorite category or Content Type.

All Clipboard

Searches recent clipboard history plus all Favorites. The empty, untyped list remains the compact suggestion view.

A selected category or type

Searches only that Favorite category or Content Type. Hiding the sidebar returns to All Clipboard but keeps and reruns your query.

  1. Click the grid icon for Content Types or the star icon for Favorites. Keyboard alternatives are ⌘T and ⌘F.
  2. Click the card you want. Arrow keys and displayed numbers are optional alternatives.
  3. Type to search inside that scope.
  4. Click All Clipboard to return to the complete collection. The optional keyboard equivalent is ⌘0.

Content Types are more than labels

Copi recognizes Table, JSON, XML, Markdown, SQL, Code, Link, Email, File Path, Number, Image and Text. A manual Password type is also available. Selecting a type shows matching clipboard entries in their normal recent-first order.

Correct a detected type

  1. Right-click the result in the overlay, or the item in Settings → History.
  2. Open Content Type.
  3. Choose the correct type, or choose Automatic to let Copi classify it again.

Arrange your type cards

  1. Open Copi and click the Content Types grid icon.
  2. Drag a card to the position you want. Neighboring cards move as you cross them.
  3. Release inside the grid to save. Releasing outside restores the previous order.

Favorites

Keep the things you use again and again.

History follows what you copy. Favorites are snippets you deliberately keep: an address, a standard reply, a booking reference, a link or anything else you reuse.

  • An optional name can show “Shipping address” instead of the full content.
  • Each Favorite belongs to one category and can be moved later.
  • Masking protects the on-screen presentation without changing its Content Type.
  • The Password type is always masked and receives extra pasteboard cleanup.

Save a history item as a Favorite

  1. Open Copi and find the result.
  2. Click the star at the right of the row. The optional keyboard equivalent is ⌘D.
  3. Choose the Favorite category. The star adopts that category’s color.
  4. Use the same menu later to move it to another category or remove it from Favorites.

Create a Favorite from scratch

  1. Open Copi and click the Favorites star icon.
  2. Click the + button at the bottom of the sidebar.
  3. Choose New Favorite.
  4. Enter the content, choose a category, and optionally add a display name or enable Mask in Results.
  5. Save. Copi automatically detects the Content Type; you can override it later.

Create and customize a category

  1. Open Favorites and click +.
  2. Choose New Category.
  3. Give it a name, icon and color.
  4. Optionally assign a letter. For example, a category assigned L opens with ⌘L while Copi is open.
  5. Right-click a category later to edit it, create a Favorite inside it, change its shortcut or delete it.

D, F and T are reserved. Category and Content Type letters share one collision-checked shortcut set.

Reorder and edit Favorites

  1. Choose a Favorite category.
  2. Drag a Favorite to reorder it, or drag it into another category.
  3. Right-click a Favorite and choose Edit Favorite… to change its name, content or masking.
  4. Press Escape in an editor to cancel without saving.

“Masked” is useful for shoulder-surfing. “Password” is a stricter Content Type with permanent masking and safer clipboard restoration behavior.

Preview & quick actions

Inspect an item—or use it without pasting.

Preview is read-only and opens only when requested. Quick Actions recognize Links, Email addresses and File Paths.

Open Preview

  1. Highlight a result with the pointer or arrow keys.
  2. Press Space. Short text stays compact; paragraphs, code, tables and images receive more room.
  3. Use ↑/↓ to inspect neighboring results without closing Preview.
  4. Press Space again or Escape to close it.

A masked value reveals only after a deliberate click inside Preview. Preview never becomes an editor.

Run a Quick Action

  1. Highlight a Link, Email or File Path.
  2. Look at Search: it changes to Open in Browser, Open in Mail or Open in Finder.
  3. Press ⌘Return.
  4. Copi opens the item directly without changing the pasteboard or recording a dispatched paste.
Website privacy: merely highlighting a Link does not contact it. Opening its Preview loads the real website with temporary, non-persistent storage; the site and its subresources can observe the normal network request and your IP address.

Context-aware suggestions

Copi can learn where an item is useful.

The algorithm asks one practical question: Where has this item previously been used? It treats where you copied something and where you later pasted it as different facts.

Copi freezes the destinationThe active app, semantic surface and focused area are captured immediately before the overlay opens.
→
You choose an itemA selection is weak evidence. A verified dispatched paste upgrades that same event to strong evidence.
→
Repeated use promotes itWhen you return to a matching destination, eligible items are scored and placed before ordinary recent history.

Four levels of destination similarity

Every past use goes into exactly one scoring tier. An exact event is not counted again as surface, application and global evidence.

40×ExactSame app, useful surface and reliable focused area or stable subcontext.
15×SurfaceSame app and semantic surface, such as Outlook Compose, but not the exact field.
5×ApplicationSame known application, without a reliable surface or exact match.
1×GlobalUsed elsewhere, or the application context is unknown.

When does a normal history item become a suggestion?

A dispatched paste is the strongest outcome Copi can verify. macOS does not tell Copi whether the destination actually consumed the data, so the wording is deliberately “paste dispatched.” Within the 180-day learning window, an item qualifies through any one of these routes:

Matching historyPromotion thresholdExample
Exact destination2 dispatched pastesThe same Link used twice in a browser Address bar.
Same surface3 cumulative dispatched pastesA standard reply used across fields in an email Compose window.
Same application5 cumulative dispatched pastesA document snippet repeatedly used somewhere in the same writing app.

Merely seeing an item is not evidence. Selecting without a dispatched paste counts at one quarter strength for scoring, but cannot satisfy promotion. Copy-source observations and global use also cannot promote an item.

Recent, specific use matters more—but repetition has limits

Evidence has a 45-day half-life and disappears from ranking after 180 days. Copi uses logarithmic diminishing returns, so the tenth repeat helps less than the first few. Confidence also reduces exact or surface evidence when the destination had to be inferred less reliably.

Show the scoring formula
event value = outcome × recency × context confidence destination score = 40 × log₂(1 + exact) + 15 × log₂(1 + surface) + 5 × log₂(1 + application) + 1 × log₂(1 + global)

Each total above is already adjusted for event outcome, age and confidence. A selection without dispatch has a 0.25 outcome multiplier; a dispatched paste has 1.00.

Cold starts, Favorites and content-aware hints

Copi can still be useful before it has enough personal history. A browser Address bar prefers Links, recipient or invitee fields prefer Email addresses, and secure fields prefer Passwords. Up to three of these semantic matches can enter the initial list. Favorites receive a small bonus, but unrelated Favorites do not crowd the default All list.

What you see: row one is always the verified current clipboard. Eligible suggestions follow, ordered by score and relevance. Ordinary clipboard history is then appended in recent-first order. Typing switches immediately to regular search results.

What context does Copi keep?

A destination can include the application, a stable surface such as Browser page or Compose, and a focused area such as Address bar, Recipient or Subject. Standard browser content may keep only the hostname. Full URLs, paths, queries, message bodies, recipient text, document names and arbitrary window titles are not learning keys. Private or uncertain browser modes suppress the hostname.

Suggestions are deterministic and processed on your Mac. The learning database stores keyed candidate identifiers and semantic context—not clipboard or Favorite text. No online AI service is involved.

Keep Copi visible

  1. Open the menu-bar menu or the Copi menu inside the overlay.
  2. Choose Always On Top. The optional keyboard equivalent is ⇧⌘P.
  3. Switch between apps while the overlay remains available.
  4. Each paste refreshes the active external destination so suggestion learning is attached to the right place.
  5. Turn the menu item off or use the window’s Close button to leave pinned mode. You can also press ⇧⌘P again.

Choose how you open Copi

  1. Open Show Copi Settings.
  2. Find Shortcut and click its recorder button.
  3. Press the new key combination you want to use.
  4. Test it from another application. Avoid a combination already owned by macOS or another app.

Review or filter History

  1. Open Settings and scroll to History.
  2. Filter by Content Type, copy-source application, or age: last hour, today or last seven days.
  3. Click an entry to copy it back to the clipboard.
  4. Right-click to correct its Content Type. Deleting a history row removes its stored payload but does not alter the current macOS clipboard.

Export or restore your setup

  1. Use Export… at the bottom of Settings.
  2. Create a separate backup passphrase and save the encrypted JSON file.
  3. Use Import… and that passphrase to restore settings, categories and Favorites.
  4. Clipboard history is intentionally not included in backups.
Advanced: Debug Logging and the explanation card

Enable Debug Logging only when diagnosing behavior. After a 0.5-second result hover, the separate diagnostic card can explain captured formats, effective type, destination classification, ranking counts, score components and storage state. Settings can reveal or clear the rotating JSONL logs. Logs exclude clipboard/Favorite payload text, password text, passphrases and encryption keys.

Privacy

Your clipboard history stays on your Mac.

History, Favorites and payload files are encrypted before they are stored. The key derived from your launch passphrase remains in memory while Copi runs.

Passwords stay masked

Items marked as Password remain hidden in results and can be revealed deliberately in the read-only Preview.

Learning stores no payload text

Suggestion records use private identifiers and semantic destination context rather than clipboard or Favorite content.

Backups are encrypted

Exported settings and Favorites use their own passphrase. Clipboard history is intentionally left out of the backup.

What the launch passphrase does

Copi derives an encryption key after you enter the passphrase. That key remains in memory and is not stored in Keychain. Copi keeps only a random salt, bounded derivation parameters and an encrypted verifier.

If the passphrase is forgotten, Copi cannot decrypt the local store. Settings offers a confirmed secure reset rather than silently overwriting it.

What happens while pasting a password

The destination can receive a password only after it briefly exists on the macOS pasteboard. Copi minimizes that interval and normally restores the previous clipboard afterward.

If the previous clipboard is the same password, Copi clears it instead. A Password copied from Settings expires after 30 seconds if nothing else replaces it.

Browser context is deliberately limited

A confidently standard browser page may retain only its hostname—not the path, query or fragment. Address-bar learning excludes the hostname. Private, Incognito and uncertain browser modes suppress it completely.

Permissions are separate

Accessibility Context helps classify the destination. Automatic Paste Events allows Copi to post one ⌘V after verifying that destination is still active. Copi does not monitor or record typing.

Why do I need to right-click Open on first launch?

Copi is signed but not notarized. On the first launch, Control-click or right-click Copi, choose Open, then confirm. Later launches work normally.

Why does Copi request Accessibility permission?

Copi uses separate permissions to understand the current paste destination and to send one paste command after checking that the destination is still active. It does not monitor or record your typing. After enabling Copi in System Settings → Privacy & Security → Accessibility, quit and reopen it.

What happens if I forget my database passphrase?

The encrypted local store cannot be recovered without it. Copi can securely reset the local store, but that starts history and Favorites again. An exported backup has its own passphrase.
